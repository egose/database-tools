# Quick Start

## Install

Install the released binaries with the embedded `database-tools` asdf plugin:

```bash
asdf plugin add database-tools https://github.com/egose/database-tools.git
asdf install database-tools <latest-version>
asdf set -u database-tools <latest-version>
```

Or download prebuilt binaries from the [GitHub Releases](https://github.com/egose/database-tools/releases) page and place `mongo-archive`, `mongo-unarchive`, `postgres-archive`, and `postgres-unarchive` in your `PATH`.

Native PostgreSQL operations also require compatible `pg_dump` and `pg_restore` clients in `PATH`. The published container image includes pinned PostgreSQL clients.

Verify the installation:

```bash
mongo-archive --version
mongo-unarchive --version
postgres-archive --version
postgres-unarchive --version
```

## Archive to Azure Blob Storage

```bash
mongo-archive \
  --uri="mongodb://<username>:<password>@cluster0.mongodb.net/" \
  --db=<dbname> \
  --az-account-name=<az_account_name> \
  --az-account-key=<az_account_key> \
  --az-container-name=<az_container_name>
```

## Schedule Backups

```bash
mongo-archive \
  --uri="mongodb://<username>:<password>@cluster0.mongodb.net/" \
  --db=<dbname> \
  --az-account-name=<az_account_name> \
  --az-account-key=<az_account_key> \
  --az-container-name=<az_container_name> \
  --cron \
  --cron-expression="0 * * * *"
```

Scheduled runs skip overlapping executions for the same job while a previous run is still active.

## Restore the Latest Managed Backup

```bash
mongo-unarchive \
  --uri="mongodb://localhost:27017" \
  --db=<dbname> \
  --az-account-name=<az_account_name> \
  --az-account-key=<az_account_key> \
  --az-container-name=<az_container_name>
```

To restore a legacy or manually named object, pass `--object-name` explicitly.

## Archive PostgreSQL to Local Storage

```bash
set -eu
postgres-archive \
  --host=postgres.example.com \
  --user=<username> \
  --database=appdb \
  --ssl-mode=require \
  --local-path=/var/backups/database-tools
```

Supply `POSTGRESARCHIVE__PASSWORD` through secret injection rather than putting it in the command line.

## Restore the Latest PostgreSQL Backup from S3

```bash
set -eu
postgres-unarchive \
  --host=postgres.example.com \
  --user=<username> \
  --database=appdb_restore \
  --ssl-mode=require \
  --aws-region=us-east-1 \
  --aws-bucket=<bucket_name>
```

`postgres-unarchive` restores into an existing database and may leave partial changes if `pg_restore` fails after it starts.
