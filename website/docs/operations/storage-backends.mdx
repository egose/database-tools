# Storage Backends

The tools support Azure Blob Storage, AWS S3, Google Cloud Storage, and local filesystem storage. Configure one or more archive backends for `mongo-archive` or `postgres-archive`; configure the matching backend for the restore command.

MongoDB managed backups default to `mongo-archive/`. PostgreSQL managed backups default to `postgres-archive/`. Automatic latest selection and retention are scoped to the configured prefix, including custom prefixes.

## Azure Blob Storage

```bash
mongo-archive \
  --uri="mongodb://<username>:<password>@cluster0.mongodb.net/" \
  --db=<dbname> \
  --az-account-name=<az_account_name> \
  --az-account-key=<az_account_key> \
  --az-container-name=<az_container_name>
```

Use `--az-endpoint` for emulator or endpoint override scenarios.

## AWS S3

```bash
mongo-archive \
  --uri="mongodb://<username>:<password>@cluster0.mongodb.net/" \
  --db=<dbname> \
  --aws-region=us-east-1 \
  --aws-access-key-id=<aws_access_key_id> \
  --aws-secret-access-key=<aws_secret_access_key> \
  --aws-bucket=<bucket_name>
```

Use `--aws-endpoint` and `--aws-s3-force-path-style` for S3-compatible services or local test backends.

PostgreSQL example:

```bash
set -eu
postgres-archive \
  --host=postgres.example.com \
  --user=<username> \
  --database=appdb \
  --ssl-mode=require \
  --aws-region=us-east-1 \
  --aws-bucket=<bucket_name>
```

## Google Cloud Storage

```bash
mongo-archive \
  --uri="mongodb://<username>:<password>@cluster0.mongodb.net/" \
  --db=<dbname> \
  --gcp-bucket=<bucket_name> \
  --gcp-creds-file=/path/to/service-account.json
```

Service account fields can also be supplied directly with the `--gcp-project-id`, `--gcp-private-key-id`, `--gcp-private-key`, `--gcp-client-email`, and `--gcp-client-id` options.

## Local Filesystem

Use `--local-path` for local archive storage. This is useful for local development, controlled test environments, or a container mounted to persistent storage.

```bash
set -eu
postgres-archive \
  --host=postgres.example.com \
  --user=<username> \
  --database=appdb \
  --ssl-mode=require \
  --local-path=/var/backups/database-tools
```
